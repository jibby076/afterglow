# Afterglow

A minimalist neon survival game where you're a glowing orb lost in pitch black darkness.

## How to Play

1. Open `index.html` in your browser
2. Press any key to start
3. Use WASD or Arrow Keys to move
4. Avoid the pink hazards
5. Survive for as long as possible

## Features

- **Dynamic Lighting** - Only a small radius around you is illuminated
- **Fading Revelation** - Areas you light up slowly fade back into darkness
- **Neon Aesthetic** - Glowing cyan light against pitch black with pink hazards
- **Particle Trail** - Leave a beautiful glowing trail as you move
- **Escalating Difficulty** - The void claims faster the longer you survive

## Tech

Pure HTML, CSS, and JavaScript with Canvas. No dependencies.
